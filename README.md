# PhotoCapture
Trying out opencv..
The code captures an image when thumbs up is shown and initializes a flask server locally which can be used to download the 
captured images via a qrcode. The images will be autodeleted after a set time. The code may contain security risks and errors. 
In the future I want to improve the ui and also get the image to be displayed using tkinter rather than the default image viewer which cannot be 
manipulated in the way I want.
